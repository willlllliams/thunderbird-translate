## 聚合邮件翻译 for Thunderbird：隐私政策

聚合邮件翻译 for Thunderbird 翻译你在 Thunderbird 中阅读的邮件。它没有自己的服务器：开发者不会从扩展收到任何数据；扩展不收集统计数据、使用数据或崩溃报告，也没有账号。

### 发送什么、发给谁

只有在你翻译邮件，或更改会改变译文的设置（显示方式、语言、服务）时，扩展才发送邮件文字：使用弹出面板中的按钮、快捷键 Alt+A、Alt+S 和 Alt+R，或者你开启的自动翻译。这时扩展把邮件各段落的文字，以及在“同时翻译邮件标题”开启（默认开启）时的邮件标题，发送给你所选翻译层级的服务。主工具栏的“标题翻译”按钮打开的标题翻译页面，会把它列出的邮件标题（最初最多 100 封，每点一次“显示更多”再加 100 封）发送给同样的服务：

| 服务 | 文字发往 |
| --- | --- |
| 谷歌翻译 | translate.googleapis.com |
| 微软翻译 | edge.microsoft.com；使用自己的 Azure Translator 密钥时，发往你的 Azure 资源的接口地址（默认 api.cognitive.microsofttranslator.com） |
| DeepLX | 你填写的 DeepLX 服务器地址 |
| DeepL API | api.deepl.com；DeepL 免费计划的密钥发往 api-free.deepl.com；或你填写的地址 |
| 百度翻译 | fanyi-api.baidu.com |
| 有道智云 | openapi.youdao.com |
| 彩云小译 | api.interpreter.caiyunai.com |
| AI 服务（OpenAI、Anthropic、Google Gemini、DeepSeek 等预设） | 设置页显示的该服务接口地址，或你填写的地址 |

开启精翻时，AI 服务还会收到整封邮件的文字（最多 20,000 个字符）作为上下文；邮件较长时，另有一个请求让 AI 服务分析整封邮件（摘要、人名与术语表、语气）。

你请求邮件的摘要与待办时（使用弹出面板的“摘要与待办”按钮、你自己设置的快捷键，或在你开启后出现在已翻译邮件上方的“摘要”按钮），摘要所用的 AI 服务会收到整封邮件的文字（最多 20,000 个字符）以及发件人、日期和标题，以便写出谁要做什么，并把“下周三”换算成具体日期。开启精翻时，请求还会附上前文所述分析中的术语表。你不请求摘要，扩展就不为摘要发送任何内容。

随文字一起发送的还有源语言和目标语言，以及属于该服务的请求设置：对 AI 服务而言是模型、提示词、温度和思考模式开关；对百度和有道而言是你的应用 ID 和用密钥算出的签名，密钥本身不发送；对 DeepL 而言是正式程度和英语、葡萄牙语的变体。你保存的 API 密钥只发给它所属的服务。邮件的收件人和附件从不发送；发件人和日期只随摘要发送，邮件标题只按上文所述发送。各服务按照自己的隐私政策处理收到的文字。

### 扩展在 Thunderbird 中读取的内容

为了翻译标题，扩展读取当前显示邮件的标题（生成摘要时还读取它的发件人和日期），并在标题翻译页面读取邮件标签页中所列邮件的发件人、日期和标题（权限“读取你的电子邮件”，`messagesRead`）。这个页面还会选中你点击的那一行对应的邮件，并在邮件标签页切换文件夹时得到通知，Thunderbird 只在有权限“查看你的邮件账户及其文件夹”（`accountsRead`）时允许这两项操作。扩展不读取账户设置，也不保存上述内容；离开你电脑的只有按上文所述发去翻译的标题，以及你请求摘要的邮件的发件人和日期。

### 你的同意

邮件文字第一次发送给某个在线服务之前，邮件上方的面板会写明服务名称、请求发往的地址以及发送的内容。标题第一次发给某个在线服务之前，标题翻译页面会在列表上方显示同样的面板。点击“允许并翻译”之前，扩展不向这个服务发送任何内容。摘要沿用同一项同意：摘要所用的 AI 服务第一次收到邮件之前，会出现同样的面板。每个服务只询问一次，你的选择记录在扩展的设置中。设置页列出你已允许的服务，“撤销”收回同意，之后面板会再次询问。

扩展只连接清单（manifest）中列出的地址。你自己填写的地址（例如本机的 Ollama 服务器或你的 DeepLX 服务器）需要经过 Thunderbird 自己的授权提示，扩展只在你点击“授权访问”或“测试连接”时显示这个提示。

### 不发送什么

离线词典和离线 Bergamot 模型在你的电脑上翻译，不发送任何内容。只使用这两项时，邮件文字不会离开 Thunderbird，扩展也不会显示同意面板。

### 不含你数据的下载

有两份列表和离线数据来自网络，其中不含任何邮件文字：

- 词典包列表和词典包本身，来自本项目的 GitHub Releases（github.com，下载会重定向到 release-assets.githubusercontent.com 或 objects.githubusercontent.com）；
- Bergamot 翻译模型列表和模型文件，来自 Mozilla（firefox.settings.services.mozilla.com 和 firefox-settings-attachments.cdn.mozilla.net）。

设置页或新手引导显示这两份列表时，扩展会读取它们；某个层级选用了词典或 Bergamot 时，Thunderbird 启动、设置改变和弹出面板打开时也会读取。词典包和模型只在你点击下载按钮时下载。与任何下载一样，这些请求会让服务器看到你的 IP 地址和所请求的文件。

### 在你电脑上保存什么

- 设置，包括 API 密钥，保存在 Thunderbird 配置文件的扩展存储（storage.local）中。与其他附加组件的数据一样，这些内容没有加密。
- 翻译与摘要的缓存，保存在同一存储中，默认最多 5,000 条。缓存保存译文和摘要，原文只以哈希值保存。设置页可以关闭和清空缓存。
- 你下载的词典包和 Bergamot 模型，保存在扩展的 IndexedDB 存储中。

卸载扩展会删除以上全部内容。
